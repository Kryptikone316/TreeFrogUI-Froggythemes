# Source and license registry

This directory records where imported artwork came from and whether it is
cleared for redistribution. The source theme archives remain in the local
development workspace; they are not silently relicensed by this repository.

Statuses:

- **Included**: pack is present here and has a license/attribution notice.
- **Review**: source is identified, but the exact redistribution terms or fork
  history still need confirmation.
- **Hold**: local notes indicate personal-use-only, missing, or otherwise
  incompatible terms. Do not publish the generated pack.

Forks should be created only after checking the upstream repository's current
license and preserving its attribution. A fork is provenance, not permission
to change the original license.
